# Zero-Drop-5G
> Zero-Drop 5G: Cryptography-Powered Backup Connectivity via NTN

❗Submitted to [5G Innovation Hackathon 2025](https://eservices.dot.gov.in/5ghackathon/) by DoT(Department oF Telecommunications) India

## Abstract
In **critical and sensitive scenarios**, such as **defense** and **disaster recovery**, _ensuring uninterrupted communication is essential_.  
Our **solution leverages 5G network slicin**g, **NTN connectivity**, and **advanced cryptographic mechanisms** _to guarantee secure failover during network disruptions_.  
The architecture integrates **TEEs** _for secure attestation_ and **ZKPs** _for privacy-preserving validation_ of failover actions.  
A **decentralized blockchain** _ensures real-time verification_ of NTN backup links and states, **ensuring mission-critical communication remains uninterrupted.**  
This solution provides **Zero-Drop 5G**, making it suitable _for environments where trust, performance, and security are paramount._

## Objective
This proposal aims to develop a resilient, cryptographically secure failover system for 5G networks, specifically designed for highly critical applications such as defense communications and disaster recovery.
The solution leverages Non-Terrestrial Networks (NTNs), such as satellite constellations, combined with 5G network slicing to guarantee uninterrupted, secure connectivity even during network failures.
By incorporating Trusted Execution Environments (TEEs) and Zero-Knowledge Proofs (ZKPs), the system ensures privacy-preserving validation and secure backup network routing, facilitating Zero-Drop 5G for the most demanding scenarios.

## Proposed Solution

Our solution combines 5G network slicing with NTN backup connectivity to ensure seamless failover when the primary terrestrial network fails.  
Key technologies include:  
- TEEs for secure handling and validation of failover actions
- ZKPs for privacy-preserving attestation of backup links
- Blockchain for auditability and continuous validation of NTN links
- Dynamic trust scoring to select the best NTN link based on mission-specific requirements, routing NTN paths based on security and performance.

### Tech Stack

- 5G Network Slicing: Mission-specific slices for dedicated services (e.g., military, emergency).
- TEEs: Secure attestation of devices and failover actions.
- ZKPs: Privacy-preserving validation of NTN backup integrity.
- Blockchain: Decentralized network for continuous liveness validation and backup state auditing.
