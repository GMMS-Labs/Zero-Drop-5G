# Zero-Drop-5G
> Zero-Drop 5G: Cryptography-Powered Backup Connectivity via NTN

❗Submitted to [5G Innovation Hackathon 2025](https://eservices.dot.gov.in/5ghackathon/) by DoT(Department oF Telecommunications) India

## Abstract
In critical and sensitive scenarios, such as defense and disaster recovery, ensuring uninterrupted communication is essential.
Our solution leverages 5G network slicing, NTN connectivity, and advanced cryptographic mechanisms to guarantee secure failover during network disruptions.
The architecture integrates TEEs for secure attestation and ZKPs for privacy-preserving validation of failover actions.
A decentralized blockchain ensures real-time verification of NTN backup links and states, ensuring mission-critical communication remains uninterrupted.
This solution provides Zero-Drop 5G, making it suitable for environments where trust, performance, and security are paramount.
